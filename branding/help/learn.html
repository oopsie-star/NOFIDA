🤖 Работа с ИИ-ассистентом

NOFIDA AI помогает генерировать идеи, анализировать дизайн и управлять библиотеками прямо из редактора. Вот как начать:

1
Настройте поставщика ИИ

Перейдите в Настройки аккаунта → NOFIDA AI → API Configuration. Добавьте ключ OpenRouter для доступа к сотням моделей.

2
Назначьте модели по ролям

Во вкладке Model Library выберите модели для задач: быстрый ответ, анализ файла, аудит дизайна. Каждая роль использует оптимальную модель.

3
Откройте ассистент в редакторе

Нажмите зелёную кнопку со звёздочкой в правом нижнем углу. Выделите объекты на холсте — ИИ получит их контекст автоматически.

4
Задайте вопрос или попросите помощи

Спросите про компоненты, попросите проверить иерархию, предложить варианты названий или порекомендовать библиотеку из каталога.

Ключевые концепции

Файл и страница

Каждый дизайн-файл содержит одну или несколько страниц. Страницы — это отдельные холсты для разных разделов проекта.

Фрейм

Основной контейнер для макетов. Фреймы могут быть экранами, компонентами или любыми ограниченными областями дизайна.

Компонент

Переиспользуемый элемент с центральным источником и копиями-экземплярами. Изменение основного компонента обновляет все экземпляры.

Библиотека

Общий набор компонентов, цветов и стилей, подключаемый к другим файлам проекта для поддержания единого стиля.

Авто-макет

Интеллектуальный контейнер, выстраивающий дочерние элементы по правилам Flexbox: направление, отступы, выравнивание.

Прототип

Интерактивные связи между фреймами с анимацией. Позволяет демонстрировать пользовательские сценарии без написания кода.
